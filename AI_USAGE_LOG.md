# AI Usage Log

A record of how generative AI (Claude, via Claude Code) has been used in this
repository. It exists for transparency with respect to the COMP2850 rule that
AI may be used **only in a supportive, tutoring capacity** for portfolio work.

Entries are appended in date order and never rewritten. Corrections are added
as new entries.

## Entry template

```markdown
### YYYY-MM-DD: <short title>

- **Tool / model:** Claude Code (<model>)
- **Work covered:** <tasks / portfolio weeks>
- **AI did:** <explanations, running builds/tests, reviews, commits, setup...>
- **Student did:** <wrote the code, made the fixes, submitted...>
- **AI-written code:** <none / exactly what and where>
- **Grey areas / notes:** <anything that might fall outside "supportive tutoring">
```
